## 📌 Proyectos destacados

### 🌲 Sistema agéntico educativo — ARAUCO × Microsoft Foundry
Proyecto aplicado para enseñar y guiar a usuarios en la construcción de soluciones con IA, mediante una arquitectura **multi-agente híbrida**.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB)
![Microsoft Foundry](https://img.shields.io/badge/Microsoft%20Foundry-0078D4?style=flat-square)
![Google ADK](https://img.shields.io/badge/Google%20ADK-4285F4?style=flat-square&logo=google&logoColor=white)

<details>
<summary><b>Ver detalles</b></summary>
<br>

- **Agentes de IA:** diseño e implementación de agentes autónomos con **Microsoft Foundry SDK** y **Google ADK**, integrados de forma híbrida para combinar razonamiento, orquestación y ejecución de tareas.
- **Arquitectura multi-agente:** flujos de orquestación, comunicación entre agentes y gestión de herramientas (*tool-calling*) siguiendo patrones agénticos avanzados.
- **Frontend:** interfaz interactiva en **React + TypeScript** conectada al ecosistema **Azure / Foundry**.

</details>

### 🚨 eduLogs — Plataforma de gestión de incidentes
Aplicación web fullstack para el tracking y gestión de incidentes. Responsable del **backend y la base de datos**: modelado relacional, endpoints REST y lógica de negocio.
